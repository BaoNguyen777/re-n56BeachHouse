# N56 Beach House — Grand World Phu Quoc

Gen Z / editorial-style landing page for N56 Beach House, built with Next.js, TypeScript, Tailwind CSS and Lucide.

## Highlights

- Oversized editorial typography + high-contrast Gen Z palette
- Responsive mobile-first layout
- Interactive room selector
- Booking.com CTAs
- Property facts based on the current Booking.com listing
- Lightweight external image URLs; no local image pipeline required

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

This repo is ready for Vercel / Netlify / any Node-compatible Next.js host.
